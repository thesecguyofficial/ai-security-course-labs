The agent's tools, written the way tool-calling APIs expect them: a name, a description the model
reads, and a JSON schema (which arguments, of which type, which are required).

{
  "type": "function",
  "function": {
    "name": "read_file",
    "description": "Read a text file from the helpdesk workspace, e.g. tickets/T-1043.md",
    "parameters": {
      "type": "object",
      "properties": {
        "path": {
          "type": "string",
          "description": "Path inside the workspace"
        }
      },
      "required": [
        "path"
      ]
    }
  }
}

The other two have the same shape:
  run_task    (command: string)   "Run a shell command in the workspace, e.g. ls kb"
  send_email  (to: string, subject: string, body: string)   "Send an email"

The model never runs these. It can only write a request to call one; agent.py runs it.
