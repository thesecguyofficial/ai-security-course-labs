# Capstone cloud part: Azure stream

Status: **coming with the Azure stream.** The Azure modules (AZ10 to AZ16) are released after the AWS stream. When
they are, this folder gets a `deployment.json` and `cloud_check.py --stream azure` rules for the same Helpdesk on
Microsoft Foundry, and the rubric's cloud row accepts it exactly like the AWS one.

Until then, do the cloud part on AWS (`cloud/aws/`), which needs no AWS account. If you have already finished the
Azure stream modules, you may describe your Azure version in `report/FINDINGS.md`; the grader marks the cloud row
from the AWS check and treats your Azure notes as extra evidence.
