# Capstone cloud part: Google Cloud stream

Status: **coming with the Google Cloud stream.** The Google Cloud modules (GC10 to GC16) are released after the AWS
stream. When they are, this folder gets a `deployment.json` and `cloud_check.py --stream gcp` rules for the same
Helpdesk on Google Cloud, and the rubric's cloud row accepts it exactly like the AWS one.

Until then, do the cloud part on AWS (`cloud/aws/`), which needs no AWS account. If you have already finished the
Google Cloud stream modules, you may describe your Google Cloud version in `report/FINDINGS.md`; the grader marks
the cloud row from the AWS check and treats your Google Cloud notes as extra evidence.
