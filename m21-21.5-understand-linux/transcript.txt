setups/hardened/policies/refund_ticket_order.cedar

  // Support agents and supervisors may refund an order that belongs to the ticket's customer.
  @id("refund_ticket_order")
  permit (principal, action == TSG::Action::"issue_refund", resource is TSG::Order)
  when {
      ["support", "supervisor"].contains(principal.role) &&
      resource.customer == context.ticket.requester
  };

Read it part by part:
  @id("refund_ticket_order")                           a name for the rule; decisions report it
  permit                                               the effect: allow when this rule matches
    principal                                          WHO: any user, unless narrowed below
    action == TSG::Action::"issue_refund"              WHAT: the action (tool)
    resource is TSG::Order                             ON WHAT: the resource
  when                                                 only if everything inside is true
    ["support", "supervisor"].contains(principal.role) &&
    resource.customer == context.ticket.requester
  (&& means AND: every line inside must be true)
